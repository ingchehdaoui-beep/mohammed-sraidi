# Site web — Mohammed Sraidi, professeur de mathématiques

Site vitrine bilingue **français / العربية** (phase 1 du cahier des charges, v1.0 — novembre 2026).

## Contenu
- Accueil, Nos cours, Niveaux scolaires, Méthode, À propos, Ressources, Témoignages, Contact
- Bascule FR ⇄ AR avec mise en page RTL (`?lang=ar` pour ouvrir directement en arabe)
- Formulaire de demande de cours → message WhatsApp pré-rempli (06 06 19 49 15)
- Formulaire compatible **Netlify Forms** (`demande-cours`) pour enregistrer les demandes
- Mention de protection des données (loi 09-08)

## Fichiers
- `index.html` : le site complet (CSS, JS et photo intégrés)
- `photo-mohammed-sraidi.jpg` : portrait extrait de l'affiche

## Déploiement Netlify
Importer ce dépôt dans Netlify, sans commande de build, dossier de publication : `/`.

## À valider avant mise en ligne
Zone d'intervention, parcours et diplômes, tarifs, orthographe arabe du nom, programmes par niveau, nom de domaine.
